# 部署与分发指南

分发源码需要Node.js24。先解压到独立目录并运行npm ci --ignore-scripts --no-audit，再运行npm run check及npm test。首次npm start生成独立runtime，不迁移原机器数据。QQ默认关闭。

设置示例中的端口，避免占用现有服务。配置DSH地址和自己的认证；Codex CLI自行安装登录。开启QQ前配置本机OneBot、自己的owner和凭据。请勿向公网暴露本机端口。邮箱、手机、屏幕、服务器、绘图和语义模型各自按需要接入。

分发包包含中性占位角色、通用源码及基础回归，排除个人角色卡、照片、私有验收资料、数据库、会话、日志、备份、运行配置和任何授权。打包转换仅作用于独立副本，不修改正在运行的个人实例。

包内README为接收者安装说明，项目README为开发和本机运维说明。发布需核对文件清单与实际ZIP、隐私扫描、解压后语法/基础回归/空数据启动；模型和QQ真实接通仍需接收方验收。
